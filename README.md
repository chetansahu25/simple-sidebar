# Setup Guide


##  Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/chetansahu25/simple-sidebar.git
   cd simple-sidebar
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

## Run the Project

Start the development server:
```bash
npm run dev
```

The app will be available at:
```
http://localhost:5173
```
